# archive

a collection of random notes and other stuff.

## Architecture

The site is built with [Astro](https://astro.build/). The notes are typeset using [Typst](https://typst.app/). The source files for the documents are in `typst-src/`. The compiled PDFs are in `public/pdfs/`.


## Local development

```
npm install
npm run dev
```
